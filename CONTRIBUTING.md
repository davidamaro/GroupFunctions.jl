# Contributing

## Do you want to report a bug?

Please open an issue, including:

- A minimal code snippet reproducing the problem: likely the definition of the partition `λ` and the two basis states (as GT patterns or as `occupation_number` vectors), and a call to `group_function`.
- The expected result and a reason why it should take the proposed form.
- The full error message with the stack trace, or, for a wrong answer, the output you got (unless the problem is excessive time/memory use, when stack traces are not produced).
- The output of `versioninfo()` and `Pkg.status("GroupFunctions")`.
- Whether `Pkg.test("GroupFunctions")` runs without errors.

## Do you want to contribute?

Please open an issue first and describe what you would like to change. The course of action and who writes the code are settled in that discussion before any pull request. 

## Do you have a question?

Please check [the documentation](https://davidamaro.github.io/GroupFunctions.jl/dev/) first, and open an issue if it is not answered there.
